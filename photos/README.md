# Picture Museum

Add up to six pictures or GIFs here. Name each file `photo-01` through `photo-06` and use a `.jpg`, `.jpeg`, `.png`, `.webp`, or `.gif` extension. For example, `photo-02.gif` will fill the second frame and play automatically.

The page checks the supported extensions for each filename, so no server or extra setup is needed. To add more than six frames, copy a `<figure class="museum-item">` in `index.html` and change its number and caption.
